# SmartLearn

A free, mobile-friendly starter prototype for low-bandwidth learning and exam practice for Nigerian students.

## Included
- Responsive home page for phones and computers
- Subject cards and WAEC, NECO and JAMB filters
- Starter notes for Mathematics, English Language and Biology
- Multiple-choice quizzes with automatic marking and explanations
- Saved lessons and quiz scores stored on the current device
- Basic service-worker caching for repeat visits/offline app shell

## Publish with GitHub Pages
1. Open repository Settings → Pages.
2. Under Build and deployment, select Deploy from a branch.
3. Choose branch main and folder /(root), then Save.
4. Wait for the published URL to appear on the Pages settings screen.

## Limitations
This is a starter prototype. There are no student accounts, cloud database, teacher/admin editor, or cross-device sync. Only sample lessons and quiz questions are included. Verify content accuracy and obtain permission for any past questions before publishing. Offline caching requires an initial online visit in a supported browser.
